# zaglushka-3x-ui
Сайт заглушка для панели 3x-ui

Установи на свой сервер ngnix: 

sudo apt install nginx -y

Открой - sudo mkdir -p /var/www/html

sudo nano /var/www/html/index.html

И вставь все из файла index.html
